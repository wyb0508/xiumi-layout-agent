# 秀米效果翻译与排版

**内部准确选机制，对外先说画面和动作。** 用户不需要先学会SVG术语。先说明“点一下会怎样、哪里变化、什么保持不动”，再给真正能照做的秀米步骤。不能用“自由滑动×遮罩×组件触发”等词组代替解释。

基础界面研究日期为2026-11-04，案例与实验更新至2026-11-06；当前界面、目标载体和实际设备优先。这个技能提供知识和方法，不自带浏览器、秀米登录状态或发布权限。

## 工作顺序

1. **听懂句子。** 有口语、代词、纠正或含混描述时读[口语理解方法](references/visual-intent-routing.md)，按需检索[口语效果词典](references/spoken-effect-dictionary.json)。结合上下文提取对象、动作、先后、停止位置、保留状态和正文高度。词典用来联想，不以关键词直接判定。保留“别、只、还、再、里面那个”等限定；“高级、丝滑、有电影感”不是具体交互机制。
2. **给一句画面解释。** 例如“每张卡都能单独点开，已经打开的会留着，别的卡不受影响。”信息足够就继续；只在不同答案会改变做法时，问一个普通话问题。静态图无法证明长按、循环或隐藏状态。按用户已有材料推进，不把推测写成观察。
3. **选载体和组件。** 公众号需求默认原生图文；独立H5、秀米链接另判。内部用[效果索引](references/effect-map.md)和[20类结构](references/advanced-patterns.md)选型，查相关[50篇案例](references/distinctive-svg-cases.json)。不要把第三方组件编号当作秀米编号。无法访问原文时明确证据范围。
4. **安排素材和可编辑位置。** 先读[换图与手调指南](references/image-replacement-guide.md)。区分封面、结果图、装饰、背景、点击区域、成对素材。能命名时用“替换｜封面照片”“保留｜点击区域”等人能理解的名字；不能命名时用页面、缩略图内容和位置定位。为交付保留真实入口与尺寸记录。
5. **制作或给流程。** 有授权且工具可用时，优先复制模板或新建实验稿；先跑通完整动作，再替图和精修。给出选哪个对象、点哪个实际菜单、改什么及原因，实际值与建议值分开。没有浏览器能力就交付操作方案，不声称已在秀米生成。用户已有正式稿先保留可恢复副本。
6. **验证所承诺的路径。** 检查初始→操作→结束→重复/返回；涉及多个选择还要检查状态是否保留。保存后重新打开确认。桌面、手机微信、导入后的结果分别记录；未测就说明。复杂组合不继承基础组件的全部测试结论。
7. **每次交付都交代如何手调。** 对这次真实作品说明：换哪张图→到哪里选中→怎么换→是否要成对换→换后检查什么；涉及文字也说明改字位置。不可只说“替换素材即可”。分析方案尚无草稿时，明确给的是通用路径；同一稿再次修改时只更新受影响的换图说明，保留能直接找到的既有说明链接。纯概念答疑无素材可换时直接说明，不编造图片位置。

## 对用户的默认表达

按任务大小自然组织，不强制六段技术报告：

- **做成什么样／已经做到哪里**：先用用户能看见的变化解释，给作品链接（若有）。
- **读者怎么操作**：点、按住、左右滑、停在哪，使用读者的动作语言。
- **你自己怎么换图／改字**：针对当前对象给具体步骤；复杂配对再附小表。菜单本身叫“SVG布局”“设置图集序列”时保留原名，并说明要选哪个框。
- **还有什么没验证**：只说本次实质限制，不用未经测量的准确率或兼容保证。

用户主动要专业名时用“口语效果 → 专业叫法 → 秀米做法”对应表；专业词是方便检索的附注，不替代解释。十组既有演示的口语说明见[十组演示交接](references/ten-demo-handoffs.md)。

## 不能丢的判断

- 下方正文被推开才是增加文章高度；固定框内换图或消失不能冒充展开。全宽展开还需比例稳定；普通文字换行和px间距可能破坏高度推算。
- 滑一下后自动播放，与手指拖到哪里进度到哪里分开；光圈视窗内移动底图，与任意跟手光源分开。
- 各卡独立保留，与整组统一切换分开；集齐后触发还需要完成条件，不能只把几个热点叠起来。
- 多层轮播核对整张画布、帧序、触发起点和总周期；不同过渡速度不等于任意不同周期。
- SVG图集并非只能放图片，但支持范围随类型、动画和交互选项而变；按专题矩阵检查。页转场与元素动画分开。
- “同步点中下一页”需手机触摸确认；桌面不响应不等于手机通过。视差也可能来自滑动与重叠而非SVG动画。
- 分支路由不自动等于计分或后台提交；换装叠图不自动等于生成可保存的合成图片；预设密码不是身份鉴权。
- 无源结构时说“可用这个方法复现”，不说“作者一定这样做”。50篇来自讲解和教程研究，不是50篇原文交互实测；143项帮助是检索索引，不代表全部精读。

## 迁移与持续改进

其他智能体可以读取本目录的SKILL.md及相关引用；`agents/openai.yaml`仅供支持它的产品使用。工具名称不要硬编码成跨产品通用接口。能读文件不代表能操作秀米，先使用目标环境实际提供的工具。

发现误判时记录“用户原话→决定性区别→正确机制→口语解释→素材替换位置→验证范围”，补判别点而不是只添同义词。更新后检查[语言回归用例](references/intent-regression-cases.json)，保留50篇来源记录和已有证据层级。只积累可复用经验，不保存登录凭据、临时预览票据或把私有草稿当作公开模板。
