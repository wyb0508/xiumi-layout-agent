# 常见效果制作配方

这些流程用于快速复现。**示例参数可以调整**，不能直接当作所有屏幕的最佳值。来源编号见 [source-register.md](source-register.md)，实测范围见 [research-evidence.md](research-evidence.md)。

## R01 点击展开普通正文

结构：SVG布局〔第1页：封面；第2页：内容页正文〕。

1. 图文模板→布局→基础布局→插入SVG布局。
2. 右侧打开布局模式，点SVG灰边框→编辑。
3. 第1页放封面图或文字；设置合适的画布比例。文字先保持简单，验证显示字号。
4. 第2页内容页输入正文。
5. 第1页“转场设置”→点击转场→顺序：淡出0.3秒→展开0.4秒。
6. 展开选固定宽，示例328px；暂不启用“同步点中下一页”。
7. 返回→保存→预览，点击封面，检查正文露出及后方模块位置。
8. 再调整封面比例、留白和字号，测小屏及微信手机端。

**已桌面跑通。** 本次样例的封面文字在桌面预览异常偏小，功能通过不等于外观定稿；要单独修正文字渲染，不能沿用缺陷样式。[S08/S09]

## R02 全宽展开图片长卷

结构：SVG封面→内容页〔同宽无缝切片/比例稳定结构〕。

1. 按目标宽高比准备封面与内容切片。
2. 拼接内容，清除图片组前后距，检查父层行距和透明边。
3. SVG封面设置点击淡出→全宽展开。
4. 检查内容中是否混入普通文字、固定px空隙、固定尺寸布局。
5. 两种屏宽预览，核对末尾无空白/截断；不稳定时改固定宽或把该部分改为比例结构。

官方方案，未在本次设备完成此配方实测。[S08/S09/S24]

## R03 点击“揭开”一张图

结构：SVG前层提示图，后层结果图；视窗高度保持一致。

1. 第1页放遮罩/提示，下一页或内容页放结果。
2. 当前页设置点击淡出，可从0.3秒开始调。
3. 若只需同框露出内容，先不加展开。
4. 要求多次来回时另选轮换结构，明确返回时是否重置。
5. 检查点击被图片原生放大拦截、透明前层仍挡交互的问题。

官方机制与当前UI已核对，具体成品需测试。[S08]

## R04 自动卡片轮播

结构：SVG图集〔同宽高比的若干图片〕。

1. 图文模板→SVG→图片轮播，选择层叠切换模板，或基础SVG图集。
2. 选中图集外层，设置图集序列；逐帧替换并核对顺序。
3. 效果选层叠切换，触发选自动。
4. 示例：切换0.6秒、停留2秒、循环；按阅读速度调整。
5. 检查边框、圆角是否原图自带，替换时保持视觉一致。
6. 保存预览，至少观察完整一轮与回到首帧。

**四图桌面轮播已实测。** 发布导入按当前模板要求并在微信验证。[S11/现场UI]

## R05 手动横滑照片卡片

结构：左右滑动布局〔卡片1、卡片2、卡片3〕。

1. 选左右滑动模板→设置滑动序列。
2. 把每个“图片+说明”先组成卡片，再作为一个序列项加入。
3. 统一卡片整体比例或约束最高项；需要露出下一张时调低项宽度，例如90%作为起点。
4. 开启“滑动时自动对齐”，并检查上下对齐。
5. 用手机拖动至中途松手，验证停靠和顺序。

90%为设计建议，非产品规定；本配方未手机实测。[S13]

## R06 小窗口查看长图 / 双向浏览地图

结构A：定高上下滑动〔长图〕；结构B：自由滑动〔多列高内容〕。

1. 先按参考决定视窗宽高比；内容总尺寸必须大于视窗。
2. 竖向长图用上下滑动；地图/大画布用自由滑动，官方基础模板#69519。
3. 设置序列，检查横向与纵向都有足够溢出。
4. 保留清楚的滑动提示，测试手指移出视窗后整篇文章仍可正常滚动。

官方配方，手机手势待测。[S13/S14]

## R07 二级选择题 / 分支剧情

结构：起始页→A页或B页→AC/AD/BE/BF四个结果页。

1. 在SVG→分支转场找到对应基础模板；从零制作时先添加并命名7个页面。
2. 起始、A、B三个问题页设置分支转场。
3. 选A热点→动画→操作点击→效果转场→转场至“A”。B同理。
4. A页两个热点指向AC/AD，B页指向BE/BF。
5. 根据需要用SVG页做结果海报，或用内容页放支持的交互内容。
6. 替换每页图和文字后重新对齐热点；保存预览。
7. 测全部可达路径，检查终点、返回和重新开始是否符合需求。

**A→C→AC路径桌面已实测**；其余路径未逐一验收。该结构不能直接等同答卷收集和累计计分，当前官方说明也不支持直接衔接展开。[S34]

## R08 点击声音并展开

结构：SVG封面→下一页中的音频/音乐组件+内容。

1. 先独立验证媒体能播放，再单独验证转场。
2. 页转场开启“同步点中下一页”；按媒体所在区域安排热点。
3. 检查动画时长、下一页层级、连续多页开启的问题。
4. 必须在手机触摸环境验证一次点击能完成两件事；桌面不响应不算失败或成功证据。

未实测媒体联动；此配方来自官方说明，不承诺自动播放。[S10]

## R09 图片/文字沿曲线运动

结构：SVG页〔独立元素+路径动画〕。

1. 先定画布宽高和元素大小。
2. 选择元素→动画→添加路径效果→编辑动画路径。
3. 选直线或曲线，完成并保存轨迹。
4. 设置时长、速度、重复/往返、沿路径方向；先只保留一个元素。
5. 若是自动运动，核对默认页转场不会提前遮挡或移走画布。
6. 预览起点、终点、回程和越界，再扩展多元素时间关系。

参数面板已核对；未把路径样例保留在实验草稿中，也未声称效果实测通过。[S18]

## R10 序列帧产品转动

结构：SVG图集→序列帧。

1. 先由设计工具输出同画布尺寸、连续编号的静帧。
2. 秀米按顺序导入，选择序列帧效果；官方示例模板#74576。
3. 设置单帧时长。若希望12帧/秒，可先用约0.083秒作为计算起点，但以UI精度与设备表现为准。
4. 观察是否跳帧、首尾是否连续，再平衡帧数、资源大小与清晰度。

帧率计算是制作建议，不是官方性能保证；本次未完整实测。[S19]

## R11 杂志式图文、贴纸与压边标题

结构：普通双列/自适应布局→图片列与文字列；装饰另用重叠/自由布局。

1. 先定页面内距、列比例、标题与正文样式。
2. 小图标用固定宽，正文用伸缩列；图片与文字不强行使用同一个固定高度。
3. 要等高时把照片设列背景并拉伸对齐，检查裁切。
4. 装饰元素选择明确参照边和层级，少量使用相对偏移。
5. 换成最长标题、最多正文和不同图片测试，再收藏模块。

官方布局方法，具体版式需按参考量取比例。[S03/S04/S06/S15]

## R12 无缝长图拼接

1. 准备同宽切片，确认原素材边缘没有白色或透明像素。
2. 使用无缝图片样式，或逐项将组前距/组后距设0。
3. 检查父布局行间距、段落间隔和多余空行。
4. 若拼在全宽展开中，继续检查比例稳定性。
5. 在预览里观察每条接缝，不能只在编辑器缩略图确认。

官方配方，未将此项单独计为本次实测。[S23/S24]

## R13 渐变字与动态纹理字

1. 选中文字，先设目标平台可用字体和字号。
2. 渐变字：文字颜色→渐变，调整颜色与方向。
3. 纹理字：文字颜色→文字纹理，选择静图/GIF，调整重复/填充方式。
4. 需要阴影、背景或多种渐变时，按兼容情况拆成独立文字组件，避免样式互相覆盖。
5. 手机微信实测，保留普通字体/纯色的替代方案；不要用微信PC判断纹理最终效果。

官方说明，未手机实测。[S20/S21/S22]

## R14 点击看另一张大图

先判参考是否微信原生看图。如果是：

1. 底层放最终大图，前层SVG放小卡片/提示图。
2. 让相应前层图片点击穿透，保持底层图片允许放大。
3. 底层高度超出前层显示框时，核对“适应点击放大”。
4. 手机验证打开的是目标图片、可退出、不会挡住正文滚动。

官方机制，未手机验证；不能把它描述为任意自定义网页弹窗。[S29]

## R15 视差模板换内容

1. 当前库核对#72234（自由滑动透视）或#71090（另加SVG淡出）。
2. 插入副本→编辑辅助→展开结构，逐一选中图片和文字。
3. 图片组件直接替换；相框、底纹去对应自由布局背景或最外层背景替换。
4. SVG内图片新旧尺寸不同时进入SVG编辑，调整画布与热点。
5. 不随意删除透明占位或透视外层，完成后手机检查两个滑动方向和点击。

官方模板改造流程，未实测此配方。[S37]

## R16 纯图点击收缩视差

这是高级组合，先做小样再精修：

1. 前后两幅画面各用重叠布局组成，图片使用适合该模板的SVG图片组件。
2. 两画面、透明SVG收缩页、外层固定比例布局使用相同宽高比。
3. 前后画面的外层开启子组件透视，各元素调Z向偏移并补偿视觉大小；该教程要求缩放时关闭缩放补偿。
4. 固定比例内按顺序放透明SVG收缩页、前画面、后画面。前画面用负组前距覆盖SVG页。
5. 负组前距按 `-(高÷宽)×100%` 算；示例1080×1687约为-156.204%，不是通用常量。
6. SVG触发层保证能接收点击，显示图片按方案设置点击穿透；外层开透视，外围普通布局行间距0。
7. 逐层排查点击和高度，再手机验收。

这份压缩配方需同时查看官方图示；尚未实操通过，不能当成已验证成品方案。[S38]

## R17 做成以后可复用的样刊

1. 先完成可编辑模块和全局基础格式，冻结不参与图片替换的装饰物。
2. 更多→将本图文设置为样刊→选择模块→分配主/次标题、图片、引用、分割线、顶部/底部签名角色。
3. 完成后在新草稿用样刊模板插入，或为正文添加对应Markdown标记后进行一键排版。
4. 测试不同标题长度和图片比例，避免装饰位被正文图替换。
5. 留一份空白母版及一份内容示例，后续从副本改。

官方流程，未将本次实验草稿转换成用户正式样刊。[S32/S33]

## R18 深色模式与目标载体检查

1. 编辑器预览检查默认、小屏、深色三个状态。
2. 图片变色时评估高亮布局；文字颜色另测，不能假设高亮布局保护所有内容。
3. 确认发布为公众号原生图文，还是秀米独立链接。背景音乐和锚点按增强模式边界处理。
4. 复杂交互通过合适的同步/插件路径进入微信草稿，再手机预览验证。

本次未执行微信导入或正式发布。[S07/S17/S30/S31/S36]
