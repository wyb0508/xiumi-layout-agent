## 必须保留的新旧差异

| 主题 | 不完整/旧说法 | 本次采用方式 |
|---|---|---|
| 图集类型数量 | 某概述列7种 | 当前UI含层叠切换，共观察到8类；不假设以后固定为8 |
| 图集能否放普通内容 | 只能图片 | 依据S12，按效果、独立动画、交互模式区分 |
| 全宽是否支持收缩 | S09的旧限制 | 后续教程和UI存在全宽收缩；对具体结构现场验证 |
| SVG是否普通复制可用 | 各说明不同 | 以当前模板/设置要求为起点，经微信实测决定 |
| 桌面无法触发复杂展开 | 笼统判断配置错 | S10证明触摸联动仅手机，但具体样例手机仍待测 |
| 免费/权限/接口限制 | 旧文章数值 | 本技能不固化，发生需求时核对当前账号和官方说明 |

## 索引使用

`official-help-catalog.json`只保存官方索引页面中的标题和URL，未下载文章全文。按词条搜索可定位音视频、表格、链接、小程序、导出等补充资料。新任务涉及尚未精读的子功能时先读对应官方页，不假装已经掌握全部操作。
