# 让用户自己换图、改字

本文件解决交付后的小改动。**每次交付都给与当前作品对应的手调说明**。用户不必读懂组件树。若只提供方案而没有实际草稿，下面的路径只能称为通用做法；不能假装已读到该模板的页名、图层名和尺寸。

## 交付前应记录什么

对本次最可能更换的图片记录以下信息，复杂作品可附一张小表；不要让用户自己猜“图层3”是什么。

| 必须说清 | 可用的定位方式 |
|---|---|
| 换哪张 | “点开后出现的汽车照片”“轮播的第2张”“画框外面的人物” |
| 在哪里 | 编辑链接、章节标题、进入的页面、看到的缩略图内容；当前实测层级 |
| 具体怎么点 | 从正文选哪个外框→进哪个编辑入口→选中哪张旧图→从图库替换→返回并保存 |
| 新图要求 | 实测的画布尺寸或比例、是否透明、图片里的字是否已烘焙；没有读到尺寸就明确未知 |
| 要不要一起换 | 前后两张、内外两张、相邻拼接图、照片与对应文字、全部分支中的同一人物 |
| 换完看什么 | 数量是否增加、主体是否错位、点击是否还有效、轮播顺序是否一致 |

能命名的模板元素用“替换｜底图”“替换｜卡片打开后的照片”“保留｜按钮点击区域”。无法命名时用页面位置和可见内容定位，不假造编辑器支持的图层名称。

正式稿先复制可恢复版本。简单替图通常保留旧图片所在的容器与动画；删掉整个容器再插新图会把动作设置一起删掉。若误插了一张，先撤销刚才那一步，再选中旧图重试，别靠删除不明元素补救。

## 已知入口与现场差异

- 普通图片：选中正文中的旧图片，再使用当前界面提供的替换方式；已观察到的常用方法是选中旧图后从“我的图库”选择新图。不同对象的工具栏不同，不保证都有名为“替换图片”的按钮。
- SVG内的图片：切到布局选择方式，选灰色外边框→“编辑”→选相应页面→选旧图。外层框、里面的图和点击区域是不同对象；不要停在外框就换素材。
- 图集：选中整个图集→“设置图集序列”→选原有项目后换图。必须观察项目数和顺序，避免变成新增一项。界面名以当前实际显示为准。
- 滑动内容：选外层→“设置滑动序列”，进入相应项编辑图片或文字。一个序列项可能是整组图文，不要把整组误换成一张图。
- 选不中：使用编辑辅助或结构层级找到对象；不要反复点击把透明点击层当成照片。菜单路径须与现场工具栏核对。

## 按图片角色选择步骤

### RIMG01 普通照片或静态版面图片

1. 从正文点中需要换的那张旧图，确认框选范围没有包含整个版式。
2. 从“我的图库”选已经上传的新图；未上传时用当前图库的上传入口，上传后回选旧图再替换。
3. 保持原比例，检查裁切是否切掉人物、车头或文字。比例改变时重新检查下面内容是否错位。
4. 回正文保存；比较替换前后，确保只换了这一张。正文文字另点文本框修改；图上自带的字需改源图片。

### RIMG02 封面、点开后底图或某一页中的图片

1. 选这组交互的灰色外框→“编辑”。先确认是封面页、打开后的页面，还是同一页中被盖住的底图。
2. 进入目标页，选那张旧图。底图被盖住时用编辑辅助定位；不要永久删除封面来找底图。
3. 从图库换图，保留画布比例和原点击区域。若图文内容本来嵌在图片里，换图同时会换掉其中的字。
4. 返回正文并保存。预览“没点时”和“点开后”两种状态；有返回按钮时再回去一次。

### RIMG03 轮播中的一张

1. 选整个轮播→“设置图集序列”，找到要换的第几张，以缩略图确认。
2. 选中原项目再替换；保留其他项目。换完项目总数应不变，顺序也应不变。
3. 新图按原画布比例准备，避免同组照片忽大忽小。原图有文字时同时核对内容是否仍对应。
4. 检查当前项、前后两项及最后一项回到第一项；自动/点击触发、停留和循环保持原设置。若另有文字图集，读RIMG10。

### RIMG04 可以滑动的一张图文卡片

1. 选滑动外框→“设置滑动序列”→进入目标卡片。
2. 只选卡片里的照片换图；标题、正文分别点各自文本框修改，保留卡片宽度和前后间距。
3. 返回并保存，左右或上下滑到相邻卡片；检查新图没有挤窄文字或造成异常空白。
4. 如果这项实际是一张整图，文字不能单独改，说明需先改图片再替换。

### RIMG05 背景、纹理或大地图

1. 先确认它是“背景图片”还是放在底层的普通图片。背景应进入所属布局的背景设置；底层图片按RIMG01/RIMG02替换。
2. 用当前界面实际存在的背景入口替换，不在上面再叠一张图。记录原来是铺满、等比显示还是可滚动大图。
3. 保持定位点和原画布比例；用于找东西的大图还要按RIMG08检查热点位置。
4. 滑到边缘查看是否露白，返回中心检查主体。新图尺寸不足时不能用放大模糊的结果冒充完整替换。

### RIMG06 透明人物、车、破框部分或前景框

1. 找到对应的透明素材层，先确认它是人物、车还是装饰框，不以“透明图”一概替换。
2. 新图要有真实透明背景，并保留与原图一致的完整画布和主体位置；不要只裁到人物轮廓。
3. 若同一个主体分为框内与框外两份，必须成对替换并对齐；如果是随轮播变化的主体，每个对应项目都要匹配。
4. 预览边缘、最大移动位置和切换瞬间；检查穿帮、断头、重复轮廓。点击层通常另外保留。

### RIMG07 前后配对图与长图拼接切片

1. 在素材说明里明确“改A时也改B”。模糊/清晰、黑白/彩色、暗/亮前后态用同一原图制作，同尺寸、同构图、同裁切。若是上下或左右拼接切片，则由完整源图按原切片边界重新裁切，保持连接处连续；它们不是相同裁切的两张图。
2. 分别进入前态和后态图片位置替换，不能只改变清晰的底图而保留旧封面。
3. 以原始画布对齐；若模糊是编辑器本身的效果而非独立图片，则只换底图，保留效果，依据实际结构决定。
4. 预览变化中途和结束后，确认主体不跳动，文字不重影，光圈或擦开范围仍在正确位置。拼接切片则检查整幅画面接缝：统一显示宽度和比例，图片及父布局的相关间距按原无缝设置保留，避免白线或主体断开。

### RIMG08 找东西、点击收集、沿线剪开的画面

1. 分清可见物体、隐藏点击区域、完成提示、路径线。改变图片不代表点击区域和路径会自动跟着移动。
2. 同尺寸同位置换物体时可先保留点击区；目标换位置、大小或数量，就需要重新对齐热点并核对完成条件。
3. 沿线剪开还要检查起点、终点和线条位置。不要把“换一张底图”说成无需调整就能继续玩。
4. 每个目标分别点一次，确认提示；有“全部完成”结果时把所有目标做完一次。触摸路径必须用实际手机测试，桌面测试单列。

### RIMG09 不同选择对应不同结果

1. 进入SVG编辑页，列出“初始选择”“选A后”“选B后”“对应结果”等**当前实际页名**。
2. 在需要变更的页中选旧图替换；同一人物或品牌跨页出现时检查每一处。改文字只进入相应文本对象。
3. 保留按钮的目标页和返回设置；更改图片不应顺便改变分支。
4. 沿所有受影响选择走到结果。只测A→C不能声称B相关结果也通过。交付时标明哪些结果仍是占位图。

### RIMG10 多组同步图片、序列帧、GIF或视频

1. 先识别：一份GIF/视频、单一序列帧，还是两组需要同步的图集。
2. GIF/视频换成完整新文件并检查尺寸、时长、循环和后续展开时机；单张静态图不能保留旧文件的内部动作。
3. 序列帧保持编号顺序、画布、帧数与节奏；需要改帧数时一起调整时间。两组同步图集按同一项目配对替换，核对触发起点和总周期。
4. 若文字是单独一组，改照片时核对同序号文字；若文字在图片内，先重制图片。
5. 预览开始、中途、最后一帧和循环接缝；多组至少检查三轮。新增素材和改时长后须重新验证后续动作，不能沿用旧测试结论。

## 可直接套用的交付句式

> **你自己换图：** 打开［本次编辑链接］，找到“［章节的口语标题］”，选［具体外框］→［现场菜单］→［实际页面］。选中［旧图看起来是什么］，再从“我的图库”选新图。新图用［实测比例/尺寸］，［需要透明／另有哪张要一起换］。保留［与动作有关的具体对象］。返回保存后［操作一次并观察具体结果］。
>
> **改字：** ［哪段文字→实际文本对象→修改→保存］；［若文字在图片里，需改源图后再换］。

把方括号填成当前实际结果，不原样交付。一个普通照片替换通常三四句话足够。多层作品只列有依赖的素材，不把所有参数抄给用户。用户只想换一张图时，不强制重走无关效果；新图影响的状态和位置仍需核对。
