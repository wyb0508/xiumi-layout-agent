# 发布兼容性与故障定位

## 先区分三种成品

| 成品 | 典型入口 | 不应混淆 |
|---|---|---|
| 微信公众号原生图文 | 秀米同步/合适复制方式→公众号草稿 | 能在秀米链接运行不证明微信相同 |
| 秀米独立图文链接 | 秀米分享/独立页面 | 增强模式可提供额外能力 |
| 秀米H5 | 独立H5制作和发布流程 | H5不能直接当原生图文同步 |

本技能重点是公众号图文，不假称覆盖H5全部页面、表单、收费和发布功能。

增强模式背景音乐只适用于独立秀米图文，复制/同步到公众号不会保留为同样的背景音乐。锚点也应按增强模式处理。公众号原生音乐/音频/视频组件与增强模式BGM是不同机制。[S07/S30/S35/S36]

## 导入方式

- **同步到公众号**上传素材/草稿，不等于群发。是否新增或更新已有素材要看当前选项，避免覆盖正式稿。
- **插件复制**与**普通复制粘贴**不能一概等同，自动对齐、SVG图集和嵌套效果可能有差异。
- 现场层叠轮播模板注明三种方式可用，但图集设置/部分旧说明更严格。因此按当前模板和参数面板要求优先选择同步/插件，并在手机验证；不要宣称所有SVG都能普通复制。
- 不从微信草稿再次复制到另一个微信草稿来判断保真；回到秀米源稿生成。
- 本研究没有新增公众号授权、安装插件、同步到微信或群发。后续用户明确要求时再按已有授权执行相应步骤。
- 不把旧文档的图片大小、接口次数、账号权限和套餐价格写成永久限制，使用时重新核对。[S11/S13/S31]

## 故障表

| 症状 | 优先检查 | 修复方向 |
|---|---|---|
| 点击展开完全不动 | 是否同步点中下一页；透明层；选错预览区域 | 手机测触摸联动；明确热点层级 |
| 点击显示看似成功但下文位置不对 | 做的是淡出还是展开 | 依据文档高度需求改转场 |
| 展开下方大空白/被截断 | 全宽内容有文字换行/px间距/滚动条 | 固定宽或整体比例稳定结构 |
| 图集只显示首图 | 编辑状态还是运行预览；触发方式 | 保存预览，核对自动/点击及循环 |
| 图集内的按钮无法点 | 效果类型、内容可交互、重叠热点 | 对照2026嵌套矩阵，先拆为单帧 |
| 图集换效果后内容消失 | 普通内容是否被不支持的类型过滤 | 用副本回退并选兼容类型 |
| 连续点击后状态混乱 | 一次性、轮换、同步、重复是否混用 | 先画状态表，逐一验证复位 |
| 分支跳错页 | 热点目标、复制页后的命名 | 读“转场至”而非凭页面位置猜 |
| 图片放大拦住按钮 | 点击放大是否启用 | 对按钮图禁用放大，保留目标图能力 |
| 应该放大却打不开 | 底图高度、前层穿透 | 核对适应点击放大与热点覆盖 |
| 滑动没有反应 | 内容是否真的超过视窗 | 约束高度/比例，再增加溢出内容 |
| 滑动卡住整篇文章 | 内外同方向滚动/手势捕获 | 减少嵌套，调整交互并手机复测 |
| 长图接缝有白线 | 图片原边、组距、父层行距、空行 | 从素材到外层逐层清理 |
| 换图后圆角/边框消失 | 原图预绘装饰或布局样式 | 将装饰补进素材或独立布局 |
| 换屏后重叠错位 | 固定偏移、锚点、文字换行 | 改相对尺寸/对齐或比例画布 |
| 深色模式变色 | 图片/文字/背景分别检查 | 高亮布局只能解决部分图片场景 |
| 字体与设计稿不同 | 字体类别、系统回退、目标设备 | 选可用字体或保留源稿后转图 |
| 纹理字微信PC看不到 | 官方已注明PC限制 | 手机确认，提供替代样式 |
| SVG文字预览特别小 | 编辑尺寸、相对字号转换、内嵌文本样式 | 最小文字样例复现，不能盲目放大所有内容 |
| 点不出图集/SVG设置 | 当前选到了内层图片或行 | 打开布局模式/编辑辅助选外层 |
| 模板显示不可编辑 | 冻结状态 | 选对象解冻，不误认为账号收费限制 |
| 预览链接失效/403 | 临时票据过期、误用公开分享地址 | 从已保存草稿重新点预览，不绕过访问限制 |

## 最小验收矩阵

每次交付填写事实，不能预先全部勾选：

| 项目 | 要观察的结果 |
|---|---|
| 保存 | 草稿标题和编辑链接可重新打开 |
| 默认预览 | 初始内容正确、媒体加载、无结构溢出 |
| 一次触发 | 热点范围、顺序、时长、目标页 |
| 重复/返回 | 明确能重来、循环、回退，或本来就是单次 |
| 小屏 | 文字换行、点击目标、固定宽不越界 |
| 深色 | 文字、图片、底色均可读 |
| iOS微信 | 触摸、内滚动、原生放大、媒体联动 |
| Android微信 | 同上，不能由iOS结果代替 |
| 导入后 | 微信草稿与秀米预览的结构和动作一致 |

首帧和终态分别截图；复杂分支至少覆盖所有终点，媒体记录是否真实播放。若只测桌面，交付写“桌面预览通过；手机微信未测”，不要写“完全兼容”。
