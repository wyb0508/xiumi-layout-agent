# SVG布局与交互逻辑

主要依据：S08/S09/S10/S18/S34；当前UI与实验见 [research-evidence.md](research-evidence.md)。

## 两层操作体系

**页面转场**决定当前SVG页如何离开、是否露出下一页/内容页；**元素动画**决定某个文字、图片、触发区的动作。选中了元素就不能把其“动画”菜单当成整页“转场设置”。

当前进入路径：图文模板→布局→基础布局→SVG布局；打开布局模式→点SVG布局灰边框→编辑。进入后可添加SVG页和内容页。SVG页用于覆盖图层与动画元素，内容页放普通图文或支持的交互内容。

编辑器“显示内容”只是方便编辑底层，不证明读者已经能展开。

## 当前界面核对的选项

| 层级 | 可见选项 | 使用方式 |
|---|---|---|
| 页交互操作 | 点击转场、长按转场、滑动转场、组件触发、轮换转场、分支转场、不转场 | 先选触发逻辑，再选效果 |
| 页转场效果 | 快闪、淡入、淡出、移入、移出、展开、收缩、掉落、打开、缩放、翻页、翻入、翻出 | 并非任意组合都允许；以当前模式可见项为准 |
| 排列方式 | 顺序、自由 | 区分串行动画和独立时间安排 |
| 元素操作 | 点击、长按、滑动 | 热点、文字、图片可各有作用区 |
| 元素效果 | 字幕、快闪、淡入、淡出、移入、移出、收缩、打开、路径、转场 | 分支页“转场”可指定目标页 |

不要用旧教程“只有7种效果”覆盖当前界面。每次制作记录用到的选项即可，不需要遍历所有组合。

## 展开高度的关键区别

### 固定宽展开

适合普通正文、预计会换行的文字。实测样例为固定宽 **328px**，先淡出 **0.3秒**，再展开 **0.4秒**。这些是样例值，不是平台要求。需检查左右留白、窄屏宽度、内容字体和高度。

### 全宽展开

适合整体比例稳定的内容：无缝图片、比例画布、按相同比例构成的图像结构。全宽展开会按宽度推算高度；普通文本换行、固定px间距、滚动条都可能使真实高度不符合推算，导致空白或截断。

先检查全部嵌套层，再决定改为固定宽，或将内层改成固定比例。不要只增加一个随意的空白撑高“修复”。旧教程对全宽收缩的限制，与后来当前UI和新教程存在版本差异，应按所用效果现场验证。

## 热点与点击穿透

- 热点只覆盖需要交互的区域，避免整页透明层吞掉图片放大、滑动和其他按钮。
- 穿透是让事件继续落到后层，不是让前层所有内容消失。
- 点击本身被原生图片放大截走时，核对图片增强→点击放大；仅对需要作为按钮/热点的图禁用。
- 热点与按钮外观是两个对象时，改图后必须核对热点坐标。
- 轮播叠加按钮还要核对内外组件点击优先级，见图集专题。

## 同步点中下一页

官方2025说明明确这是**手机触摸功能**，桌面点击无效。用于一次触摸既转场，又触发下一页中的音乐、图集或动画。[S10]

判断顺序：是否启用→下一页可触发对象在哪→是否连续多页同时启用→元素动作是否正确串接转场→手机实测。官方建议动作有足够时长（示例至少约0.2秒）、缩放起始100%；重复展开/收缩和连续页启用等组合有限制。该值不是全部动画的性能或兼容阈值。

## 分支转场

先制作状态表，例如：

| 当前页 | 点击区域 | 下一页 |
|---|---|---|
| 起始 | A | A |
| 起始 | B | B |
| A | C | AC结果 |
| A | D | AD结果 |
| B | E | BE结果 |
| B | F | BF结果 |

页面命名后设“分支转场”。选热点→动画→点击→转场→“转场至”指定命名页。可以多个入口汇入同一页；页序调整不会要求凭页码重建所有逻辑，但改后仍检查目标。

官方说明：同一SVG布局至多一组分支转场；分支后的扩展可放在末端内容页中；当前该结构不能直接衔接展开。不要未经验证把分支、展开、轮换和返回混成一个通用组件。纯展示分支没有证明后台答卷存储、概率随机或累计得分能力。[S34]

## 长按、轮换与组件触发

长按页/元素动画可涉及松开暂停、回退、继续；图集长按能力更受限，不能互相套用。做手势交互需实测松开瞬间、离开热点和第二次按下。

轮换适合一组状态反复切换。返回上一视觉状态不代表全部子动画被重置；需要定义每次返回的初始状态。

组件触发用于把某元素动作衔接到整页转场。2026模板中可见“路径→滑动触发→淡出/展开”等组合，但本研究仅核对模板说明，未完成手机端拖动实测。

## 路径和字幕

路径入口：SVG页内选择元素→动画→添加效果→路径→编辑动画路径。**先定画布尺寸再绘路径**，避免改高后轨迹错位。

可核对：显示组件/轨迹/二者；匀速、加速、减速、先加速后减速；重复、往返、沿路径自动调整方向。高级路径可用直线、二次/三次曲线、连续曲线、弧线和移动点，也可按官方流程导入Illustrator路径。[S18]

旧编辑模式的红点拖动与新路径设计界面并存，不给用户编造统一按钮。完成路径需保存结束，再确认动画设置。默认页淡出若与持续自动运动冲突，先检查是否应删除。

字幕/弹幕首先判断是可编辑文字动画、GIF还是整张图的移动。视觉相近不代表素材类型相同。
