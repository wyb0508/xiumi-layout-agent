# 十组演示：用日常话说明与交接

对应实验集《SVG高阶交互实验集｜10种动画组合》，2026-11-06保存并重开确认10组存在。使用秀米现有模板组合和说明文字，不是全部从零绘制的品牌定稿。以下是**已观察的动作＋今后替图时要检查的素材角色**；并未逐一进入每张内部图片核实槽位名称、尺寸或完成换图，因此不能把本表冒充十份已实测的替图操作单。

## 真正给用户做下一稿时

1. 先用上表第二列解释；专业组合只在用户想了解或需要搜菜单时附上。
2. 选中要复用的那组，进入编辑辅助确认真实页、图、热点与序列。不能用“之前测试过”跳过新素材检查。
3. 按[换图指南](image-replacement-guide.md)记录当前图片位置、比例和配对关系，生成这份作品专用的换图说明。
4. 以用户所需动作验证，不把桌面滚动替代手机拖动，也不把一条分支通过写成全路径通过。

没有证据证明十组全都在手机微信或公众号导入后正常；最难不代表每个组合都已达到最终可发布状态。
