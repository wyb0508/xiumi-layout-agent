# 秀米网页操作备忘

这是本次操作积累，不覆盖当前工具安全规则。使用时先读取浏览器工具最新文档，不能复用过期元素索引或临时URL。

## 进入正确编辑层

1. 打开用户草稿或新建实验稿，确认标题。
2. 普通图片工具条没有SVG设置时，通常选错层级。
3. 打开右侧布局模式（四格图标），点击SVG布局较粗的灰边框。
4. 应看到“SVG布局 / 动画 / 编辑 / 显示内容”，再点“编辑”。
5. 复杂/被遮挡对象使用“小眼睛”编辑辅助，展开结构树选择。必要时给层命名。
6. 编辑页面中区分“转场设置”和选元素后的“动画”。
7. 返回外层后等待转换结束，保存，再预览。

## 稳定操作方式

- 优先语义定位，如“保存”“转场设置”。页面有多个同名按钮时按所属页/面板限定，不任意取第一个。
- SVG画布内部热点不一定有可访问文本，可根据最新截图点坐标；弹窗关闭或页面自动滚动后重新观察。
- 一次点击后的可访问树可能短暂仍显示旧态。不要立即盲目再次点击；检查截图或相关DOM判断是否已生效。
- 文字全选替换前先确认焦点在该文本组件，避免选中整页。
- 普通图文、自由布局、SVG布局各有自己的返回和保存流程。

## 图集替换

图集外层→设置序列；选某一帧再点图库通常替换，未选帧时可能追加。每次核对数量、顺序、比例和选中状态。模板自带说明常包含组件类型、推荐比例、支持的导入方法，优先读这些说明。

## 预览验证

点预览可能要求先保存，用户登录后继续即可，不重复询问已经完成的登录。

编辑器手机外框中的预览通常位于iframe。如果浏览器工具无法安全点击其缩放坐标，可以读取**当前页面实际生成的iframe预览地址**，在同一已授权浏览器的新页打开该临时预览。这是使用产品已有预览入口；不能编造票据、改公开审核状态或绕过访问控制。

临时预览会过期；保存长期编辑链接，后续重新生成。别把临时URL写进技能、报告或最终分享链接。

预览里的“默认/小屏/深色”方便检查视觉，不能代替iOS/Android微信触摸与导入后验证。

## 原则与收尾

- 实验只改新建或复制的草稿；不为研究改正式文章、公众号授权、套餐或公开发布状态。
- 截图记录初始、设置、终态；终态与预期一致后才报告通过。
- 保留用户需要的编辑/预览页，关闭研究临时页。
- 按当前CUA工具要求调用完成总结，再进入其他工具步骤或回复。
- URL被安全策略拦截时如实说明；不通过切换代理、读取缓存或另一个浏览器绕过。
