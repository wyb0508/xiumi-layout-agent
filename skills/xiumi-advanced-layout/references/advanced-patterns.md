# 20类特色SVG结构与秀米转译

案例编号对应[50篇索引](distinctive-svg-cases.md)。案例事实来自独立讲解；本文件的秀米搭建方法是基于已知组件能力提出的方案，**20类不是全部已验证**。2026-11-06新增十组原生模板演示，仅部分动作在桌面被观察，范围见[十组交接](ten-demo-handoffs.md)和[研究证据](research-evidence.md)。不能把“基础展开测试通过”提升为“整个高级效果验证通过”。

## 共用操作基线

- SVG布局入口：图文模板→布局→基础布局→SVG布局；布局模式→选灰边框→编辑。页转场与元素动画分开操作。[详细步骤](svg-interactions.md)
- 普通横滑入口：模板→布局→滑动布局；选外层→设置滑动序列。竖滑必须先限定视窗高度或比例。[滑动与嵌套规则](galleries-and-sliding.md)
- SVG图集先选效果，再填序列；触发、时长、停留、循环、可交互选项以当前类型的实际字段为准。已有8类效果不等于支持任意组合。
- 所有配方先固定画布比例、素材锚点和初始状态。多张对应图片必须统一**整张画布**，仅主体尺寸相同仍会错位。透明素材使用真实Alpha。
- 本文“先测”指下一次制作时的最小验证，不是已完成测试。没有对应参数时，报告差距；不发明秀米菜单或挪用i排版组件编号。

## P01 路径与正文联动

案例：C02、C10、C27、C29、C42。秀米路径、展开、元素入场有依据；完整联动待测。

1. 拆成底图、移动主体、线条、章节四类素材；先决定正文是初始已占高度还是逐段撑开。
2. 在SVG页固定画布，选主体→动画→添加效果→路径→编辑动画路径。先放节点再画轨迹，检查主体锚点与轨迹起点。
3. 给章节分别配置移入/淡入。依据主体到达章节位置的时刻设置延时；如果界面只有时间控制，这就是时间编排，不能称为实时碰撞触发。
4. 光点移动、整线显现、线条逐段绘制分别处理。只有移动路径能力时，画线可用外部序列帧近似；不要把路径动画等同于描边生长。

先测：两站路径、两个章节、重播一次。验收主体到达时章节才显现，重播无旧状态残留。长文章不宜直接拉成一个极高SVG画布；分段后要重新验证衔接。

## P02 多层视差、夹层滑动与斜面

案例：C03、C12、C20、C24、C26、C28、C32、C36、C40、C44。官方视差与自由滑动方案可作起点，完整案例待测。

结构：外层比例视窗→后景→可移动中层→前景透明框；必要时另加近景。准备超出视窗的移动素材，避免露底。

1. 先用普通横滑实现“中层动、边框不动”。边框独立重叠，滑动序列放在中层，按比例对齐。
2. 若前后景都要不同速度移动，核对官方视差模板结构，参考#72234或#71090；编号需现场确认。不能仅重叠两个独立滑动框就宣称联动视差。
3. 斜面先确认是图像本身倾斜，还是内容经过透视变换。素材斜裁与容器转动会产生不同触摸方向和裁切边界。
4. 给前层透明区域检查点击穿透，测试拖动距离、往返、边缘露白及页面竖滑冲突。

“向上滑”要分别写清手指向上、素材向上、读者看到主体上升哪一种；它们不一定相同。Z深度、缩放补偿和负间距按原比例结构计算，不套固定魔法数值。

## P03 定向显露、扫光与擦除后展开

案例：C05、C45、C46。案例教程支持“两张等大图→擦除→展开”的拆法；秀米没有在本研究中确认通用“擦除”菜单。

1. 准备同构图的前态与后态，例如暗/亮、模糊/清晰。叠加检查主体完全对齐。
2. 确认遮罩是自动移动边界，还是手指经过处留下擦痕。一次点击开始播放的擦除不要求持续采样手指位置。
3. 若当前模板具备所需定向显露，先只测试两张图；再在末态连接展开内容。擦除时长与展开时长分别控制。
4. 缺少对应模板时，可把定向转变制作成GIF或序列帧，再接SVG展开，标为视觉近似。它不能保留随手指擦除的自由轨迹，且接续时机需验证。

光带扫过后持续变亮与移动手电筒是不同机制，后者转P12。验收：边界方向、前后图位置、擦完后高度、重复点击、展开末尾无截断。原教程的补高度经验不能替代秀米的比例高度计算。[展开规则](svg-interactions.md)

## P04 分步穿越、旋转与交替离场

案例：C06、C25、C37、C41、C43。共同点是有限步骤的视觉推进，具体变换不可混用。

1. 列状态表：点击次数→当前画面→变换类型→下一画面。区分平面转动、绕轴翻面、中心缩放、平移离场。
2. 圆洞穿越用各帧同位置的洞口作缩放锚点；平面旋转先标旋转中心；左右飞卡逐步指定方向。
3. 在SVG页转场或图集选对应效果，以当前可用字段实现。叠卡优先检查“层叠切换”；翻面不是“转动”的同义词。
4. 最后一步再单独连接展开；前几步固定视窗，避免每次动作改变全文位置。循环时明确回到第一帧还是保留最后一帧。

没有可设锚点/角度的原生效果时，可预制序列帧近似。先测两步与末步，不先制作完整几十帧。验收每次点击恰好推进一次，快速连点不跳过关键内容。

## P05 独立热点、宫格和长场景

案例：C07、C16、C26、C30、C41。核心是“操作A后，B保持不变”，不能用单个全局轮播替代。

1. 按网格或自由布局固定每个单元；单元内用独立SVG状态或图片切换，外层只负责排版。
2. 每个单元分别定义关闭/打开/复位；需弹层时明确关闭入口。原生图片放大与自定义文字弹层分开选择。
3. 长场景中的热点跟随内容坐标，不固定在视窗坐标。若滑动框包含交互内容，按图集内容矩阵检查嵌套支持与点击优先级。
4. 验证A→B→A、滑走再回来、外层轮播回到这一帧时的状态。组件回环可能重置内部状态。

新增边界：2026-11-06“集齐月影”模板观察到四个目标各自打勾，集齐后出现结果。这个模板的完成触发成立，不代表任意独立热点布局自动拥有汇总功能；改目标数量仍需核对结构。

16格不等于已证实4列，也不等于3D翻牌。若需要点击次数统计、持久记忆或全部打开后自动解锁，先另查能力；独立显示不自动提供跨单元汇总状态。

## P06 翻面题卡与场景分支

案例：C08、C21。基础分支有桌面样例，完整题库、计分未测。

1. 把题目写成状态表：当前题→选项→解释/下一题/重试。独立题卡各自一组，连续故事才共享路线。
2. 添加并命名SVG页；设分支转场；选热点→动画→点击→转场→转场至目标页。错误答案与正确答案不要共用错误的下一页。
3. 翻面表现另用页转场或图集翻转效果验证，不因“背面答案”自动引入旋转动画。
4. 检查同一SVG布局至多一组分支的约束。分支不能未经验证直接接展开；需要高度变化时先用单条末端路线试验结构。

可用有限页面预先列出少量结果，不能宣称真实累计计分、输入校验或后台答卷。验收所有分支出口及重试路线；只走通一条路径不算全部通过。

## P07 多入口展开、收回与互斥

案例：C09、C23、C34。基础展开已测，可反复收回及复杂组合待测。

1. 先确定多面板能否同时打开。独立章节分成多个SVG布局；互斥切换需验证跨面板状态联动，不默认具备“手风琴”控制器。
2. 每项准备封面、内容、明确的收回入口。先选择适合内容的固定宽或比例稳定全宽结构。
3. 在当前模板核对展开/收缩的循环方式，做一项开→关→再开。不要仅淡出内容留下原来高度。
4. 弹性/回弹是运动曲线，不是“展开”必然附带。无对应曲线时标明近似，不能给出不存在的“弹性强度”字段。

验收正文下方标记能随开合上下移动；收回后没有空白、透明热点或无法再点的封面。分支入口接展开及手机同步触发需按[限制](svg-interactions.md)另测。

## P08 时间轴、档案和互动报纸

案例：C11、C12、C15、C30。保留索引、版面与方向设计，不将普通横滑本身当作新发现。

1. 列出信息层级：年代/词条/版面→条目→详情。时间顺序与屏幕移动方向各占一列。
2. 时间轴使用按序段落与滑动/转场；倒带需要另列反向帧序，不靠“反向播放”一词推定组件支持。
3. 档案采用纵向分节、节内横滑；每项图片与说明放同一布局，避免标题和照片滑到不同项。
4. 互动报纸先定栅格和跨栏比例，再给版面各区布置热点。大幅底图加热点可保外观，但正文变为图片时须交代编辑和阅读代价。

目录跳到另一状态用P19；公众号原生锚点跳转未确认时不许给出“链接到本页某段”的伪操作。验收返回后位置、窄屏字大小、内外滑动冲突。

## P09 模拟聊天与社交界面

案例：C14、C16。做预设叙事，不把UI外观等同于实时服务。

1. 写“用户点击→固定回复→下一入口”脚本，记录每段新增的高度。聊天头像、气泡、日期、提示条分别成组。
2. 短轮次可用分阶段SVG转场/展开；只需固定视窗换内容则用状态页。新消息增长到视窗外与整篇文章变长是两种排版。
3. 封面上移揭开动态页使用明确移出方向；点赞图标与评论气泡各自放热点，不让整张截图吞掉所有点击。
4. 从两轮样例测试快速连点和返回，再扩展脚本。不可编辑截图需要外部制图；可编辑气泡则检查缩放后的字号。

任意输入、联网生成、真实点赞数量、分享统计属于另外的产品能力。没有依据时提供预设演示的范围，用户确实要业务功能时再说明载体选择。

## P10 多轴换装、场景拼接与壁纸

案例：C13、C17、C18。显示组合与导出合成图是两项能力。

1. 列选项轴，例如天空×车身×地面，数量为a、b、c；列出是否独立、有无禁止组合。总组合a×b×c用于评估素材量，不代表必须把所有组合预先渲染。
2. 独立轴可做成独立滑动行或独立切换图层；统一画布比例、拼接基线和遮挡顺序。需要联动限制时改成明确的有限状态路线。
3. 换装准备透明部件与固定人物底图；禁止自动裁掉每张素材周围透明边，否则切换会跳位。
4. 若只需展示，验证各轴变化互不复位；若还需长按保存整图，先确认输出机制。多个SVG/图片叠成一幅视觉画面，并不自动生成单张可保存图片。

可选近似：有限候选海报预先合成，末页显示单张结果图；代价是组合数量受限。自由编辑、实时合成、导出与持久保存需要额外实现，不能由案例标题“专属壁纸”推导已经可做。

## P11 序列素材、片头与视频接续

案例：C19、C20、C22、C37、C40。外部素材通常是主要工作量。

1. 拆出装饰外框、连续画面、触发按钮、后续正文。材质变化/光影渲染/摄影镜头先制作成连续帧或视频，SVG负责呈现与控制。
2. 图集先选序列帧或适用切换，再加入同画布帧。帧间隔由目标播放时长÷帧数起算，实机性能另测。
3. 接续正文时确认是固定延时还是确有播放结束事件。普通GIF可能已在页面加载时播放，点击显露不保证从第1帧重播。
4. 视频保持独立播放能力，检查封面与首帧接缝；不能承诺自动有声播放或所有微信环境无缝启动。

验收冷打开、等待后再点、快速连点、再次进入、弱网首帧。用固定时间遮罩模拟加载不等于检测真实资源已加载完成。

## P12 随手指移动的聚光灯

案例：C23、C38。当前技能没有证据证明秀米普通SVG布局可直接绑定任意拖动坐标，按**需核对专用模板或定制**处理。

2026-11-06“森林探照镜”已观察到固定圆形窗口内用桌面双向滚动查看大图；“月下寻踪”找到目标并点击后出现海报。这是视窗滑动与热点的具体证据，不能升级为光圈任意跟手或自动照到即命中。

结构分析：暗层/遮罩→透光窗口→清晰底图，另加目标热点。光圈位置、热点命中、完成后的展开是三个变量。

1. 先核对用户要跟手照亮，还是点击播放预设扫光。后者可转P03；前者不能用自动移动圆形冒充。
2. 查当前模板是否支持连续拖动与目标判定，并阅读其素材层级说明。只看到“滑动转场”不能证明它输出实时手指坐标。
3. 若有适配模板，先做一张底图、一个光圈、一个目标；验证拖到任意位置、松手停留、离开边界和热点启用条件。
4. 原样能力无法确认时，提供定点照亮或预渲染动画的可执行近似，并明确失去跟手自由度。不要先声称做得到，再用动图掩盖差异。

## P13 沿线切开与对齐解锁

案例：C01、C35。属于手势带完成条件；普通“滑动一下转场”不足以证明等价。

1. 把输入条件写明：任意划动、沿指定轨迹、到终点、图形对齐阈值。按需区分，别给所有“划开”都增加拼图判定。
2. 画出初态、拖动中、完成、松手未完成四态。把刀移动/拼片移动与结果显露分层。
3. 秀米路径与组件触发可作为研究起点；需当前模板实证路径进度或完成条件是否可用。不能从“支持路径”推导任意碰撞检测。
4. 若只能在划动后播放固定切开动画，标注为近似。真实对齐、回弹、错误提示需要专用结构，核实后才给具体参数。

验收短划、反向划、没对齐松手、重复划和滑动正文。失败输入不应误解锁；成功后不可仍被透明触发层阻挡阅读。

## P14 预设密码与加载入口

案例：C39。密码式呈现不等于安全门禁。

1. 确认输入形态：点按钮序列、有限选项，还是键盘任意文本。只为叙事解密时可将有限点击序列表示成状态图。
2. SVG分支页分别命名输入进度、错误、成功；热点指向对应状态；设置清除/重试路线。先做短序列，再评估状态页规模。
3. 成功后的加载遮罩单独作为视觉阶段。要接展开时再次核对分支结构限制，不把两个模板直接串起来视作通过。
4. 涉及账号、付费、个人信息或真实权限时，此视觉方案不承担鉴权；按用户实际需求选有后台验证的载体。

验收错误序列、回退、重试和重复进入。未验证真实数据提交时不得给出“密码已安全保存”“只有正确用户可见”等结论。

## P15 曲面屏与人物破框轮播

案例：C47；[制作教程](https://ipaiban.com/idea/article/6a9e3218082331dd9e867a5f)解释了三层结构。它是平面素材叠置的空间错觉。

结构：底部完整场景序列→中间固定透明弧形边框→顶部人物透明切图序列。上层人物在边框前，形成破框效果；并非让普通图片沿真实曲面弯曲。

1. 给每张底图制作同画布的人物切图，保持人物位置不变；两组数量与顺序一一对应。
2. 在比例画布内重叠两个图集与中间固定框。先用两帧核对首帧位置；可交互内容需遵守图集嵌套矩阵。
3. 两图集的触发起点、切换时长、停留、方向与循环都必须对应。仅设置“都是自动播放”不足以证明同步。
4. 连续看至少三轮并测试触发后重播。若当前秀米结构无法保持同步，改为单组预合成连续帧，标明失去图层独立交互与编辑能力。

验收人物边缘无白边、不会在画框交界重复出现、顶部切图未被外层裁掉；链接热点按最上层实际命中检查。

## P16 透视框中的差速轮播

案例：C50；[制作教程](https://ipaiban.com/idea/article/6ad1b0a1082331dd9e129372)。两层短时速度不同，但用相同周期避免长期错帧。

结构：底部照片轮播→透明文字轮播→固定透视框。两移动层同画布、同帧数、同帧序、同起始相位。

1. 先让两层完全同步，验证画布和顺序，再调整各层停留/过渡的分配。
2. 在每帧均匀定时的前提下，令每层“停留＋切换”的总和相同。教程示例分别为0.8＋2.2秒和1.0＋2.0秒，均为3秒；这些是案例参数，非秀米默认值。
3. 以当前图集是否允许分开设置这些字段为准。相同总和仍需相同触发起点；每帧独立动画还需核算实际总周期。
4. 观察至少三轮、末帧回首帧和触发重启；若漂移不能消除，可预合成为单条序列保留视觉节奏。

真正长期不同周期会不断改变图文配对。除非用户要这种错配，不要把“差速”解释为任意两个播放速度。

## P17 相机变焦与双层工序联动

案例：C48、C49；[制作教程](https://ipaiban.com/idea/article/6aa8becb082331dd9eb7d1c1)。来源组件属于i排版；以下是秀米适配思路，非同名现成组件承诺。

1. 拆为背景、上层序列、下层序列；配对帧数量一致、画布一致。变焦主体的中心位置稳定；工序型按阶段编号配对。
2. 先确定读者一次滑动是否必须同时驱动两层。两个各自能滑的容器不等于联动。
3. 当前秀米模板若能同步驱动，先搭两个焦段/两个工序的小样，核对停止时是否吸附到对应帧。连续跟手变焦与离散焦段切换分别验收。
4. 同步手势不能实现时，可将配对上下帧预合成一张，再组成单一滑动序列；这能保持配对，但失去双层独立速度的视差。

变焦近似还需素材本身呈现景别变化，给同一张图片放大不一定还原镜头透视。检查边框固定、主体不跳动、两层不在不同阶段停留。

## P18 分块错峰弹起与宫格切换

案例：C44。与P05的区别是整幅画面的分块动画，不必具有每格独立选择状态。

1. 准备前后完整画面，统一画布；先查看SVG图集“宫格切换”是否符合所需方向与分块方式。
2. 只在当前效果提供对应字段时调整块数、顺序、延时。不要承诺所有宫格效果都可逐格自定义。
3. 若需要特定的对角线波纹/错峰曲线，先拆两行小样；无对应原生能力时外部生成分块动画，再由SVG触发。
4. 分块遮罩必须无缝，禁止一像素边缘漏底；后续横滑或点击属于独立阶段。

验收首末状态拼接一致、错峰顺序正确、重播没有部分格停在旧图。用户说“翻格子找礼物”优先转P05，而非本类。

## P19 目录进入、宽幅阅读与返回

案例：C15、C33。固定舞台内换状态与真实增加文章高度分开设计。

1. 列出目录、阅读A、阅读B与返回路线。先决定返回后是否记住阅读进度。
2. 同一固定比例区域可用分支页路由；内容里要放图集/滑动时，先验证支持的内容种类与事件模式。
3. “双栏点开全宽”可改变区域内的视觉结构，不能默认进入系统全屏；若要把下方正文推开，另走P07并核对分支衔接限制。
4. 返回按钮放在可见且不被外层滑动截获的位置；验收A→返回→B以及B滑到末尾后返回。

未验证状态记忆时默认只承诺返回入口视觉，明确进度是否复位。公众号正文内跳锚点与组件状态返回不是同一种操作。

## P20 跨区域、多手势叙事

案例：C04、C31。作为高难度识别卡保留；当前不提供未经实证的一键秀米配方。

1. 将故事写成有限状态图：唤醒→探索→发现→完成。每条边注明单击/双击/长按/内层滑动/文章滚动，不能只写“交互”。
2. 标记每个状态是同一组件内部还是跨文章远距离位置。跨组件共享变量、整页滚动联动、回到顶部和离开后存档均需分别核对。
3. 先在单个SVG舞台中验证最短闭环。若只能顺序转场，能复现的是预设故事，不能声称具备自由小游戏或跨区条件触发。
4. 对原生图文无法确认的交互，给保留叙事的近似方案；只有用户确实需要动态状态能力时才讨论独立H5等其他载体。

验收误触、重复进入、关键步骤被跳过、状态复位与手机双击行为。读者看到“成长”不证明有真实数值系统；看到“回到开头”也不证明使用了原生锚点。
