# 图集、滑动与视差

依据：S11/S12/S13/S14/S19/S25/S37/S38，详见 [source-register.md](source-register.md)。

## SVG图集的配置顺序

1. 先选择效果类型，再决定内容结构；复杂内容填完后贸然换效果可能过滤内容。
2. 准备相同比例的序列图；设置图集序列。选中某一帧再点图库图片通常是替换，未选中时才是追加；每次看序列结果。
3. 确认触发方式：点击、单步点击、自动、长按。
4. 调整动画时长、停留、方向、循环和尺寸，以当前效果实际显示字段为准。
5. 配置内容是否可交互、是否同步触发，再处理图片放大和点击穿透。
6. 保存后验证首帧、每次切换、最后回到首帧、重复操作。

当前界面发现8类：抽签、滚动、切换、宫格切换、层叠切换、转动、翻转、序列帧。旧概述列7类并不意味着层叠切换不存在。

| 效果 | 适用外观 | 参数重点 |
|---|---|---|
| 滚动 | 同方向连续换图 | 滚动方向、时长、停留、序列比例 |
| 切换 | 各帧不同进出场 | 每帧进出方向和独立动画 |
| 层叠切换 | 卡片错层轮播 | 层次、位移方向、素材预置边框 |
| 宫格切换 | 多块拼接切换 | 分块效果、整体图像一致性 |
| 转动/翻转 | 转盘、卡片翻面 | 变换轴、画面裁切、背面显示 |
| 序列帧 | 连续动作 | 帧序、每帧时长、总素材量 |
| 抽签 | 快速轮换后停图 | 点击/松开行为；不等于概率系统 |

本次四图层叠轮播实测：自动，切换0.6秒，停留2秒，循环。生成SVG一轮10.4秒，与4×(0.6+2)一致；仅解释此样例，不推广为所有效果时长公式。

## 2026图集内容支持矩阵

2026-07-22官方说明更新了旧“只能图片”的边界：[S12](https://c.xiumius.cn/board/v6/CqiLZ/1P3jWX)。

| 图集条件 | 可考虑的内容 | 需要检查 |
|---|---|---|
| 抽签 / 无独立动画的滚动 | 普通布局、滑动、图片、音视频等交互内容 | 外层整体比例一致，优先固定比例结构 |
| 任意图集效果 + 可交互且同步触发 | 纯SVG结构、SVG图集 | 不能据此允许任意普通内容；不支持时SVG内容页会被过滤 |
| 长按触发 | 图集自身动作 | 官方说明不支持内容交互 |

“不可交互”不保证链接和小程序点击全部被禁用。不要将该选项当安全隔离开关。

普通内容和SVG嵌套分开判断：滚动一组可点击照片，与滚动一组内含另一图集的纯SVG，并不是同一套优先级。

## 嵌套点击与同步

- 外层与内层热点重叠时，谁先响应受效果类型和交互模式影响。抽签/普通滚动的交互模式、同步触发模式不能混为一谈。
- 同步触发可让多层动作同时开始；设延时可以让内层先运行。官方特定秀米链接示例使用0.01秒延时，不是全部公众号必须值。
- 开启图集点击穿透后，可能触发背后对象；需验证触摸开始和点击结束两个阶段。
- 一轮结束回到首项时，内部组件可能复位，不能默认保留之前状态。
- 嵌套SVG有点击与自动动画时，按官方组合要求核对自动页是否设“不转场”。
- 高度变化、内容页、分支和音视频混用，必须先做一帧小样再扩展。[S12]

## 普通滑动

### 左右滑动

模板→布局→滑动布局；选中外层→设置滑动序列。序列项可放图、文字、布局；每项宽度影响一屏显示多少。小于100%可露出下一项，大于100%可浏览宽图。视窗高度通常由最高项决定，要统一尺寸避免大块空白。

“滑动时自动对齐”是停靠整项，不是上下居中。同步/插件导入路径更稳；普通复制可能损失自动对齐能力。支持反向设置时要连同内容顺序一起检查。[S13]

### 上下滑动

先给外层视窗高度或比例，再放超出视窗的内容。若容器一直随内容长高，看起来就不会有内部滚动。内外同方向滚动在手机上可能争抢手势，尤其展开层嵌套竖向滚动时要实测。

### 自由滑动

官方基础模板编号 **#69519**。删除默认占位序列，准备内容到秀米剪贴板再加。单项足够高产生纵向溢出，多项横排形成横向溢出，两方向都有溢出才能任意方向浏览。固定的是视窗，不是整个内容尺寸。[S14]

### 快速变换

多选现有内容→变换组件旁下拉→快速变换→横滑/竖滑/SVG图集。转换后检查配对关系、顺序和初始效果；转换成图集不代表原来的所有交互都被支持。“清除组件格式”可能拆掉外框，操作前复制留底。[S25]

## 视差与透视

先分两类：滑动内容的前后景位移差；点击收缩时不同深度图层产生空间感。只看截图不能区分。

官方模板 **#72234**：自由滑动与透视组合，先通过编辑辅助换图、换字；背景框架要在对应自由布局/外层背景中替换。**#71090**另加SVG点击淡出，SVG图换尺寸时进入内部编辑器重排。[S37]

更复杂的点击收缩视差涉及：同宽高比的前后重叠画面、透明SVG收缩页、外层固定比例、透视开关、各图Z向偏移、点击穿透、负组前距和外层行间距0。Z值会改变视觉大小，调整缩放时检查缩放补偿。不要只抄一个“Z=某数”认为所有图都会得到正确效果。[S38]

本研究视差仅完成官方流程阅读和模板说明核对，未完成从零搭建与手机运行验证。
