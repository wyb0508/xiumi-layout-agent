# 布局、文字与素材

来源编号见 [source-register.md](source-register.md)。以下是操作决策，非所有模板的固定默认值。

## 选对对象层级

秀米的图片/文字组件、组件行、单元格、外层布局可以分别拥有宽度、边距和背景。修改前先打开右侧布局模式，确认灰框属于哪一层；复杂嵌套打开“小眼睛”编辑辅助，从树中选对象。图片后图标与布局背景图是两种不同素材位置。[S03/S26/S37]

| 想改变什么 | 应选对象 | 常见误操作 |
|---|---|---|
| 一张图片的显示宽度 | 图片组件 | 改整列，连带挤压正文 |
| 左右两栏比例 | 外层多列布局/单元格 | 改图片宽度却期待列宽变化 |
| 卡片文字离边框距离 | 卡片布局内边距 | 用空格或很多空行推位置 |
| 两个模块的上下间隔 | 组件组距/父布局行间距 | 只清图片边距，遗漏父层 |
| 装饰物压在标题上 | 重叠布局与定位 | 无参照地反复拖负边距 |
| 底纹、框架图 | 对应布局背景 | 只在图片组件里寻找 |

## 宽度与尺寸选择

- **百分比宽**：主体按父容器缩放。列宽总和、列间距、外距共同检查，不能只看加起来是否100%。
- **固定px**：适合小图标、已确定宽度的文字展开视窗；窄屏要再验。
- **适应内容**：适合短标签；文字变长后会改宽度。
- **伸缩/自适应**：固定图标旁的剩余空间交给正文。先固定装饰列，再让主列伸展。
- **固定布局**：宽高是px，溢出可能被裁切。
- **固定比例布局**：高度随宽度同比变化。图像、自由排布插画优先；不能把它等同固定像素高度。
- **自由布局**：按画布比例编辑元素位置，适合海报。复杂装饰在内层固定比例，长正文保持普通流式布局。[S03–S06/S15/S16]

## 对齐与重叠

1. 先用水平/垂直对齐，再用必要的小偏移；居中不能靠某一个屏宽下的固定左移。
2. 选参照边：徽章压卡片右上角，应锚定卡片右/上侧；不要相对页面左边硬算位置。
3. 重叠布局明确每层顺序。层级数值决定覆盖关系；透明图上看似空白处仍可能挡点击。
4. 缩放、透明度和变换会影响层叠表现。不要把99%透明度之类技巧当稳定通用规则。
5. 内容等高时可用拉伸对齐。照片作为背景铺满可获得等高，但会产生裁切，需确认主体未被切掉。
6. 比例画布中的偏移/组距尽量用相对值。某些复合SVG全宽效果要求各层同宽高比，见对应配方。[S04/S06/S38]

## 背景、边框、阴影

背景可用纯色、渐变、图片。先判断需要完整看图、填满裁切还是拉伸变形，再选适应方式。背景图不会像普通图片一样贡献相同的文档高度。边框、圆角、阴影可在布局层构造；如果模板注明白边和圆角已绘制在原图中，替换前要补进新素材。[S03/现场模板]

全局基础格式管理页面内距、字体、字号、行距、字距、颜色和默认图片样式。先定全局，再做局部例外。建议建立项目自己的基础格式收藏，不把某篇教程中的默认10px间距当成永久产品默认值。[S23]

## 字体和文字特效

| 功能 | 操作入口 | 限制与验收 |
|---|---|---|
| 字体 | 文字工具条→字体 | 优先“公众号可用”；“长图可用/所有字体”范围不同，系统字体有回退 |
| 渐变文字 | 文字颜色→渐变 | 旧官方说明限制同一行多种渐变，并与文字背景/阴影/下划线等有组合限制；拆组件复现更稳 |
| 图片/GIF填充文字 | 文字颜色→文字纹理 | 选择重复/填充/拉伸；官方注明微信PC不支持，手机验收 |
| 海报固定字形 | 自由布局，必要时文字转图 | 保留可编辑源稿；图片化会损失选字、检索和直接修改能力 |
| 自由布局文字 | 进入自由布局编辑 | 文字框留余量，核对最窄目标屏与换行 |

不根据字体列表或教程里笼统表述作版权许可保证；按素材/字体实际授权使用。[S20/S21/S22]

## 素材准备清单

- 图片同组先统一宽高比，分辨率按实际显示与清晰度选，不盲目设统一超大尺寸。
- 前景装饰需要透出后景时使用真实透明素材；白底JPG不会自动变透明。
- 长图切片保持同宽、边缘一致；检查原图自身白边、透明像素和压缩接缝。
- 轮播准备每帧；序列帧按编号排序。图片文件名不能代替在编辑器中确认顺序。
- 背景、图片组件、SVG页背景、SVG页中的图片须分开记录，换图时不要漏一层。
- 某些SVG模板通过编辑辅助直接替换时要求原尺寸一致；尺寸不同进入SVG编辑器替换并重排热点。[S19/S24/S37]

## 收藏、冻结、样刊

1. 调好的单模块收藏，整套栏目制作样刊。菜单：顶部“更多”→“将本图文设置为样刊”→框选模块→设置成样刊模板→完成。
2. 一键排版样刊给主标题、次标题、图片、分割线、引用、顶部/底部签名分别指定模板。
3. 待排文字使用 `# `、`## `、`> `、`---` 等标记，再“更多”→“一键排版”。这不是通用Markdown渲染器的全部语法支持。
4. 装饰贴纸先冻结，防止图片替换填入装饰位。设置→允许冻结编辑组件；布局工具条→冻结。想拆模板时选择被冻结对象→解冻。
5. 冻结保护编辑结构，不等于运行时禁用点击或媒体交互。
6. 系列排版更新时先验证一个长标题、一个短标题、横图、竖图，再推广到整篇。[S32/S33]
