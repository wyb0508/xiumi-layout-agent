# 秀米排版助手

把想要的画面说出来，助手会把它拆成可在秀米中操作的步骤，并告诉你以后怎样自己换图、改字。例如，你可以说“读者点哪张卡，哪张就打开。再点第二张时，第一张还留着。”

收到这句话，助手会给每张卡分别安排封面和点开后的画面。预览时先点第一张、再点第二张，确认两张都保持打开。换第二张卡的结果图时，通用做法是进入第二张卡的 SVG 编辑页，选中点开后看到的旧图，再从“我的图库”选新图。保存后重走这两个动作。助手进入过具体草稿时，也会提供该稿的页面位置、素材比例和需要一起换的图片。

## 在 GitHub Copilot 使用

在支持自定义 agent 的 Copilot 中选择本仓库和默认分支，再选择 **xiumi-layout** 并发出需求。可以直接粘贴上一段的卡片需求试用。[GitHub 自定义 agent 使用说明](https://docs.github.com/en/copilot/tutorials/customization-library/custom-agents/your-first-custom-agent)

## 在本地使用

把仓库克隆到本机。如果使用 Codex 桌面版，打开这个仓库作为项目，直接用中文描述你的需求。使用已登录的 Codex CLI 时，在仓库目录运行以下命令即可得到一次答复。启动脚本适用于 macOS、Linux 或 WSL。

```sh
./xiumi "点一下把模糊的车图变清楚，下面的正文别动。告诉我怎么换成自己的照片。"
```

运行 `./xiumi` 可进入连续对话。可以继续说“把外面的框留着，只换里面的车”。图片和录屏可通过支持相应附件的宿主界面提供。

## 在秀米生成草稿

提出“帮我在秀米做出草稿”时，助手需要宿主提供浏览器操作能力，并能进入你的秀米编辑器。登录由你在秀米页面完成。具备这些条件时，助手按要求编辑、保存并预览，再返回实际草稿和本稿的换图步骤。仅能读取仓库的环境可提供组件选择、搭建步骤与素材准备说明。
